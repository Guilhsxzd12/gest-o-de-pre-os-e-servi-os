# Videira Gestão & Precificação

Aplicação web simples para gestão de custos e precificação da Videira Vinhoteca.

## Recursos
- Calculadora de preço por produto
- Preço Pix e cartão com taxas separadas
- Custos de embalagem, variáveis e fixos
- Campo configurável para impostos/reserva e DAS
- Análise de margem e diagnóstico
- Cadastro local de produtos calculados
- Dados persistidos no navegador via localStorage
- Layout responsivo e sem dependências

## Publicação
Projeto estático: basta publicar a raiz na Vercel, sem comando de build.

> Os campos tributários são configuráveis e não constituem orientação contábil.
